This Android app shows the Grok Org OS desk UI by connecting to the FastAPI server on your PC (the same process started by Start.bat).

  1. On Windows, double-click Start.bat (server on port 8000).
  2. Find your PC’s LAN IP (e.g. ipconfig → IPv4).
  3. In the app, open Settings and set Server URL to http://<LAN-IP>:8000.
  4. Emulator tip: default http://10.0.2.2:8000 maps to the host PC.
  5. Phone and PC must be on the same Wi‑Fi; allow Windows Firewall for Python/port 8000.
Bundled desk assets are included under assets/www/ for this offline message. Once the API is reachable, use Open Desk to load {server}/ live.
