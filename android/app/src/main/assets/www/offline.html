Grok Org OS

This phone app is standalone by default — it embeds a local backend on 127.0.0.1 and needs no PC.

Open Desk loads the full org GUI (agents, HQ channel, tasks, Run Demo) from the on-device server.

Mock LLM works offline. In the desk ⚙ Settings, you can paste an OpenAI-compatible API key for live models.

Advanced: app Settings → Remote server URL to point at a PC running Start.bat / grok-org serve.
